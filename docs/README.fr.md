# Editor-like Reading View

[English](../README.md) | [日本語](README.ja.md) | [简体中文](README.zh-CN.md) | [繁體中文](README.zh-TW.md) | [한국어](README.ko.md) | [Español](README.es.md) | **Français** | [Deutsch](README.de.md)

Le mode lecture range généralement votre note : plusieurs lignes vides deviennent un seul espace, l'indentation disparaît (ou devient un bloc de code) et plusieurs espaces n'en font plus qu'un. Ce plugin affiche le mode lecture comme l'éditeur affiche votre note.

## Fonctionnalités

Chaque partie peut être activée ou désactivée dans les réglages.

- **Lignes vides entre les blocs** : chaque ligne vide après la première devient une ligne d'espace.
- **Lignes vides entre les éléments de liste** : chaque ligne vide entre les éléments de liste et de liste de tâches devient un espace.
- **Lignes vides au début de la note**, aussi après les propriétés.
- **Indentation** : les lignes indentées avec des espaces ou des tabulations restent indentées, au lieu de devenir du code. Les listes ne changent pas.
- **Espaces et tabulations dans les lignes** sont conservés, au lieu d'être affichés comme un seul espace. Le code ne change pas.
- **Citations et encadrés** : leurs lignes vides et leur indentation sont aussi conservées.
- Fonctionne sur ordinateur et sur mobile.
- Les réglages sont disponibles en anglais, japonais, chinois simplifié, chinois traditionnel, coréen, espagnol, français et allemand. La langue suit celle d'Obsidian au premier lancement.

## Bon à savoir

- Seul le mode lecture change. Vos notes ne sont pas modifiées.
- Les blocs de code, les blocs mathématiques et les commentaires restent tels quels.
- Vous voulez un PDF identique ? [PDF Preview Print](https://github.com/H9-G/pdf-preview-print) applique les mêmes règles au PDF et à l'impression.

## Utilisation du réseau

Aucune. Le plugin fonctionne hors ligne et ne collecte aucune donnée.
