# Editor-like Reading View

[English](../README.md) | [日本語](README.ja.md) | **简体中文** | [繁體中文](README.zh-TW.md) | [한국어](README.ko.md) | [Español](README.es.md) | [Français](README.fr.md) | [Deutsch](README.de.md)

阅读视图通常会整理笔记：多个连续空行变成一个间隔，缩进消失（或变成代码块），多个空格变成一个。此插件让阅读视图像编辑器一样显示笔记。

## 功能

每一项都可以在设置中开启或关闭。

- **块之间的空行**：第一个之后的每个空行都变为一行空白。
- **列表项之间的空行**：列表和清单项之间的每个空行都变为空白。
- **笔记开头的空行**，包括属性之后的空行。
- **缩进**：用空格或制表符缩进的行保持缩进，而不是变成代码。列表不受影响。
- **行内的空格和制表符**按原样保留，不合并为一个空格。代码不受影响。
- **引用与标注**：其中的空行和缩进也会保留。
- 可在桌面端和移动端使用。
- 设置支持英语、日语、简体中文、繁体中文、韩语、西班牙语、法语和德语。首次使用时跟随 Obsidian 的语言。

## 须知

- 只改变阅读视图的显示，不会修改笔记内容。
- 代码块、数学公式块和注释保持原样。
- 希望 PDF 也一样？[PDF Preview Print](https://github.com/H9-G/pdf-preview-print) 在生成 PDF 和打印时使用相同的规则。

## 网络使用

无。插件可离线运行，不收集任何数据。
