# Editor-like Reading View

[English](../README.md) | [日本語](README.ja.md) | [简体中文](README.zh-CN.md) | [繁體中文](README.zh-TW.md) | **한국어** | [Español](README.es.md) | [Français](README.fr.md) | [Deutsch](README.de.md)

읽기 보기는 보통 노트를 정리해서 보여 줍니다. 연속된 빈 줄은 하나의 간격이 되고, 들여쓰기는 사라지거나 코드 블록이 되며, 여러 공백은 하나가 됩니다. 이 플러그인은 읽기 보기를 편집기와 같은 모습으로 보여 줍니다.

## 기능

모든 기능은 설정에서 켜고 끌 수 있습니다.

- **블록 사이의 빈 줄**: 첫 번째 이후의 빈 줄마다 한 줄의 여백이 됩니다.
- **목록 항목 사이의 빈 줄**: 목록과 체크리스트 항목 사이의 빈 줄이 여백이 됩니다.
- **노트 시작 부분의 빈 줄**, 속성 뒤의 빈 줄도 포함합니다.
- **들여쓰기**: 스페이스나 탭으로 들여 쓴 줄은 코드가 되지 않고 들여 써집니다. 목록은 바꾸지 않습니다.
- **줄 중간의 공백과 탭**은 하나로 합치지 않고 그대로 표시합니다. 코드는 바꾸지 않습니다.
- **인용과 콜아웃**: 안의 빈 줄과 들여쓰기도 유지합니다.
- 데스크톱과 모바일에서 모두 작동합니다.
- 설정은 영어, 일본어, 중국어 간체, 중국어 번체, 한국어, 스페인어, 프랑스어, 독일어로 볼 수 있습니다. 처음에는 Obsidian의 언어를 따릅니다.

## 알아 두기

- 바뀌는 것은 읽기 보기의 모습뿐입니다. 노트 내용은 바꾸지 않습니다.
- 코드 블록, 수식 블록, 주석은 그대로입니다.
- PDF도 같은 모습으로 만들고 싶다면 [PDF Preview Print](https://github.com/H9-G/pdf-preview-print)가 PDF와 인쇄에 같은 규칙을 씁니다.

## 네트워크 사용

없습니다. 오프라인으로 작동하며 데이터를 수집하지 않습니다.
