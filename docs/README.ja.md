# Editor-like Reading View

[English](../README.md) | **日本語** | [简体中文](README.zh-CN.md) | [繁體中文](README.zh-TW.md) | [한국어](README.ko.md) | [Español](README.es.md) | [Français](README.fr.md) | [Deutsch](README.de.md)

リーディングビューでは、続けて入れた空白行が1つにまとめられ、字下げは消え（またはコードブロックになり）、続けて入れたスペースも1つになります。このプラグインは、リーディングビューをエディタと同じ見た目で表示します。

## できること

どの機能も、設定でオン・オフできます。

- **ブロックの間の空白行**: 2行目以降の空白行を、その数だけ空白にします。
- **リストの項目の間の空白行**: リストやチェックリストの項目の間の空白行を空白にします。
- **ノートの先頭の空白行**: 本文の最初（プロパティの後も）の空白行を空白にします。
- **インデント**: スペースやタブで字下げした行を、コードにせず字下げして表示します。リストは変えません。
- **行の途中の連続スペース・タブ**: 1つにまとめず、そのまま表示します。コードは変えません。
- **引用とコールアウト**: 中の空白行と字下げも、エディタと同じように表示します。
- パソコンとスマホの両方で動きます。
- 設定画面は、英語、日本語、簡体字中国語、繁体字中国語、韓国語、スペイン語、フランス語、ドイツ語で表示できます。最初はObsidianの言語に合わせます。

## 注意

- 変わるのはリーディングビューの見た目だけです。ノートの中身は変えません。
- コードブロック、数式ブロック、コメントはそのままです。
- PDFも同じ見た目にしたい場合は、[PDF Preview Print](https://github.com/H9-G/pdf-preview-print) が同じルールでPDF作成と印刷をします。

## ネットワークの利用

ありません。オフラインで動き、データも集めません。
