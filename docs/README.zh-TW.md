# Editor-like Reading View

[English](../README.md) | [日本語](README.ja.md) | [简体中文](README.zh-CN.md) | **繁體中文** | [한국어](README.ko.md) | [Español](README.es.md) | [Français](README.fr.md) | [Deutsch](README.de.md)

閱讀檢視通常會整理筆記：多個連續空行變成一個間隔，縮排消失（或變成程式碼區塊），多個空格變成一個。此外掛讓閱讀檢視像編輯器一樣顯示筆記。

## 功能

每一項都可以在設定中開啟或關閉。

- **區塊之間的空行**：第一個之後的每個空行都變為一行空白。
- **清單項目之間的空行**：清單和核取清單項目之間的每個空行都變為空白。
- **筆記開頭的空行**，包括屬性之後的空行。
- **縮排**：以空格或定位字元縮排的行保持縮排，而不是變成程式碼。清單不受影響。
- **行內的空格和定位字元**按原樣保留，不合併為一個空格。程式碼不受影響。
- **引用與標註**：其中的空行和縮排也會保留。
- 可在桌面版和行動版使用。
- 設定支援英語、日語、簡體中文、繁體中文、韓語、西班牙語、法語和德語。首次使用時跟隨 Obsidian 的語言。

## 注意事項

- 只改變閱讀檢視的顯示，不會修改筆記內容。
- 程式碼區塊、數學公式區塊和註解保持原樣。
- 希望 PDF 也一樣？[PDF Preview Print](https://github.com/H9-G/pdf-preview-print) 在產生 PDF 和列印時使用相同的規則。
