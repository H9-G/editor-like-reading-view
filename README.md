# Editor-like Reading View

**English** | [日本語](docs/README.ja.md) | [简体中文](docs/README.zh-CN.md) | [繁體中文](docs/README.zh-TW.md) | [한국어](docs/README.ko.md) | [Español](docs/README.es.md) | [Français](docs/README.fr.md) | [Deutsch](docs/README.de.md)

Reading view usually tidies your note up: several empty lines become one gap, indentation disappears (or turns into a code block), and several spaces become one. This plugin shows reading view the way the editor shows your note.

## Features

Each part can be turned on or off in the settings.

- **Empty lines between blocks**: every empty line after the first one becomes a line of space.
- **Empty lines between list items**: every empty line between list and checklist items becomes space.
- **Empty lines at the start of the note**, also after the properties.
- **Indentation**: lines indented with spaces or tabs stay indented, instead of becoming code. Lists are not changed.
- **Spaces and tabs inside lines** are kept, instead of being shown as one space. Code is not changed.
- **Quotes and callouts**: empty lines and indentation inside them are kept too.
- Works on desktop and mobile.
- The settings are available in English, Japanese, Simplified Chinese, Traditional Chinese, Korean, Spanish, French and German. The language follows Obsidian on first use.

## Good to know

- Only reading view changes. Your notes are not changed.
- Code blocks, math blocks and comments are left as they are.
- Want a PDF that looks the same? [PDF Preview Print](https://github.com/H9-G/pdf-preview-print) uses the same rules for the PDF and for printing.

## Network use

None. The plugin works offline and collects no data.
